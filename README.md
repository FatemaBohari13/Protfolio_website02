# 🎨 UI/UX Designer Portfolio

## 📌 Project Overview

This project is a modern and responsive UI/UX Designer Portfolio website designed to showcase design skills, projects, services, and professional information.

The portfolio was developed using HTML, CSS, and JavaScript with a clean, minimal, and user-focused interface. It includes sections for About, Skills, Projects, Services, and Contact.

The objective of this project was to create a professional portfolio that presents UI/UX design work in a simple, visually appealing, and responsive layout.

## 🚀 Key Features

* Responsive navigation bar with mobile menu
* Hero section with introduction and call-to-action buttons
* About Me section with design philosophy and career objective
* Skills section covering design, tools, development, and expertise
* Projects section showcasing Finora, Foodie, and Learnly
* Services section for UI/UX Design, Web Design, Prototyping, and Design Systems
* Contact section with contact details and message form
* Social media links section
* Smooth scrolling navigation
* Hover effects and reveal animations
* Responsive design for desktop, tablet, and mobile devices
* Reduced-motion support for accessibility

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, Grid, Gradients, Animations & Responsive Design)
* JavaScript
